    **src/lib/dsp/fft-processor.ts:**
    Export class `FftProcessor`:
    ```typescript
    import webfft from 'webfft';
    import { generateBlackmanHarris } from './window-functions';

    export class FftProcessor {
      private fft: ReturnType<typeof webfft>;
      private fftSize: number;
      private alpha: number;
      private windowCoeffs: Float32Array;
      private avgSpectrum: Float32Array;
      private windowedInput: Float32Array;
      private iqFloat: Float32Array;
      private dcI: number;
      private dcQ: number;

      constructor(fftSize: number = 1024, alpha: number = 0.3);
      process(rawIq: Uint8Array, offset: number, sampleCount: number): Float32Array;
      updateConfig(config: { fftSize?: number; alpha?: number }): void;
      dispose(): void;
    }
    ```
    - `process()` converts unsigned 8-bit IQ to float [-1,1], removes DC via IIR filter (alpha=0.001), applies Blackman-Harris window, runs webfft FFT, computes dBFS magnitude with FFT shift (DC centered), applies EMA averaging.
    - IQ conversion: `float = (uint8 - 127.5) / 127.5`
    - DC removal: `dc = dc * 0.999 + sample * 0.001; corrected = sample - dc;`
    - Magnitude: `mag = sqrt(re*re + im*im) / fftSize; db = mag > 0 ? 20*log10(mag) : -150`
    - FFT shift: display bin i = FFT output bin `(i + fftSize/2) % fftSize`
    - EMA: `avgSpectrum[i] = alpha * db + (1 - alpha) * avgSpectrum[i]`
    - All buffers pre-allocated in constructor, reused across calls.
    - `updateConfig()` re-creates webfft instance and all buffers if fftSize changes. Updates alpha in-place.
    - For the webfft constructor: `new webfft(fftSize)`. Call `this.fft.fft(this.windowedInput)` which returns interleaved complex Float32Array.
