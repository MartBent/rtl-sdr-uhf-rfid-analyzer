    2. Create `src/lib/protocol/gen2-crc.ts` with lookup-table CRC implementations:

    CRC-16/GENIBUS: polynomial 0x1021, preset 0xFFFF, XOR-out 0xFFFF, residue 0x1D0F.
    CRC-5: polynomial 0x09, preset 0x09, residue 0x00.
    Both operate bit-by-bit (Gen2 commands are NOT byte-aligned).

    Pre-compute CRC16_TABLE (256-entry Uint16Array) at module load:
    ```
    for i in 0..255: crc = i << 8; for j in 0..7: crc = (crc << 1) ^ ((crc & 0x8000) ? 0x1021 : 0); table[i] = crc & 0xFFFF
    ```

    Export functions: crc5(bits: number[]): number, validateCrc5(bitsWithCrc: number[]): boolean, crc16(bits: number[]): number, validateCrc16(bitsWithCrc: number[]): boolean.

    Note: The crc16 function processes bit-by-bit since Gen2 frames are not byte-aligned. The lookup table is used for the byte-at-a-time fast path when possible, but bit-level fallback is primary.

    Actually, since all Gen2 data is bit arrays (not bytes), implement bit-by-bit CRC directly:
    - crc16: preset=0xFFFF, for each bit: msb=(crc>>15)&1, crc=((crc<<1)|bit)&0xFFFF, if msb: crc^=0x1021. Return crc^0xFFFF.
    - validateCrc16: crc16(bitsWithCrc) === 0x1D0F
    - crc5: preset=0x09, for each bit: msb=(crc>>4)&1, crc=((crc<<1)|bit)&0x1F, if msb: crc^=0x09. Return crc.
    - validateCrc5: crc5(bitsWithCrc) === 0x00

    Delimiter detection: Look for a low pulse with duration within 20% of 12.5us (in samples: 12.5e-6 * sampleRate). At 2.4 MSPS: 30 samples +/- 6 samples (24-36 range).

    After delimiter: next high-duration symbol is data-0 (Tari). Next low-to-high-to-low cycle is RTcal = data-0 + data-1. Pivot = RTcal / 2.

    classifySymbols: for each symbol, if durationSamples < pivot -> 0, else -> 1.

    1. `identifyCommand(bits: number[]): Gen2CommandType` -- match command prefix:
       - bits[0..1] === [0,0] -> 'QueryRep' (2-bit code "00")
       - bits[0..1] === [0,1] -> 'ACK' (2-bit code "01")
       - bits[0..3] === [1,0,0,0] -> 'Query' (4-bit code "1000")
       - bits[0..3] === [1,0,0,1] -> 'QueryAdjust' (4-bit code "1001")
       - bits[0..3] === [1,0,1,1] -> 'Select' (4-bit code "1011")
       - bits[0..7] === [1,1,0,0,0,0,0,0] -> 'NAK' (8-bit code)
       - bits[0..7] === [1,1,0,0,0,0,0,1] -> 'ReqRN' (8-bit code)
       - else -> 'Unknown'

       Important: Check longer codes first to avoid ambiguity. 8-bit codes (NAK, ReqRN) must be checked before 4-bit or 2-bit codes when bits start with [1,1,...].

    2. `decodeCommand(bits: number[], sampleOffset?: number, sampleRate?: number): Gen2Command` -- identify and parse:

       Query (22 bits total): code[4] + DR[1] + M[2] + TRext[1] + Sel[2] + Session[2] + Target[1] + Q[4] + CRC-5[5]
       - DR: 0='8', 1='64/3'
       - M: 00='FM0', 01='Miller2', 10='Miller4', 11='Miller8'
       - TRext: 0=false, 1=true
       - Sel: 00='All', 01='All', 10='~SL', 11='SL'
       - Session: 00='S0', 01='S1', 10='S2', 11='S3'
       - Target: 0='A', 1='B'
       - Q: 4-bit unsigned integer (0-15)
       - CRC-5 validated over all 22 bits using validateCrc5

       QueryRep (4 bits): code[2] + Session[2]
       - crcValid: null (no CRC)

       QueryAdjust (9 bits): code[4] + Session[2] + UpDn[3]
       - UpDn: 110='up', 000='none', 011='down' (per Gen2 spec table 6.18)
       - crcValid: null

       ACK (18 bits): code[2] + RN16[16]
       - rn16: 16-bit value from bits 2..17
       - crcValid: null

       NAK (8 bits): code[8], no fields
       - crcValid: null

       Select (variable): code[4] + Target[3] + Action[3] + MemBank[2] + Pointer[EBV] + Length[8] + Mask[Length bits] + Truncate[1] + CRC-16[16]
       - EBV (Extensible Bit Vector) for Pointer: read 7-bit chunks, MSB=1 means more chunks follow, MSB=0 is last chunk
       - Parse fixed fields first, use Length to determine mask size, then parse remaining
       - CRC-16 validated over all bits using validateCrc16

       ReqRN (40 bits): code[8] + RN16[16] + CRC-16[16]
       - CRC-16 validated over all 40 bits
