    2. Create `src/lib/wasm/demod.c` implementing the envelope detector:

    The C code implements a stateful edge detector that converts raw uint8 IQ samples into pulse timing events. It maintains persistent state across calls (critical per Pitfall 4 in RESEARCH.md).

    **Exported functions (EMSCRIPTEN_KEEPALIVE):**

    `int demod_process(const uint8_t* iq_data, int byte_count, int sample_rate, DemodSymbol* output, int global_sample_offset)`
    - Iterates over byte_count/2 IQ sample pairs
    - For each sample: convert uint8 I,Q to float (-1..1) via (val - 127.5f) / 127.5f
    - Compute envelope magnitude: sqrtf(iVal*iVal + qVal*qVal)
    - Track noise floor with slow IIR: noise_floor = noise_floor * 0.999f + env * 0.001f
    - Hysteresis edge detection: threshold_high = noise_floor * 3.0f, threshold_low = noise_floor * 2.0f
    - On rising edge (was below, env > threshold_high): record previous low-pulse duration, start high-pulse
    - On falling edge (was above, env < threshold_low): record previous high-pulse duration, start low-pulse
    - Output DemodSymbol struct: { int32_t sample_offset, int32_t duration_samples, int32_t symbol_type (0=low,1=high), float amplitude }
    - global_sample_offset param added to sample_offset so timing is continuous across calls
    - Returns number of symbols written to output buffer

    `void demod_reset(void)`
    - Reset all persistent state: noise_floor=0.01f, edge_state=0, last_edge_sample=0, sample_counter=0

    `float demod_get_noise_floor(void)` -- return current noise floor estimate

    `int demod_get_state(void)` -- return current edge_state (0 or 1) for debugging

    **Persistent static variables (survive across process() calls):**
    - `static float noise_floor = 0.01f;`
    - `static int last_edge_sample = 0;`
    - `static int edge_state = 0;` (0=below threshold, 1=above)
    - `static float threshold_high = 0.0f;`
    - `static float threshold_low = 0.0f;`
    - `static int sample_counter = 0;` (running count across calls)

    **Output struct (packed for easy HEAP reading):**
    ```c
    typedef struct {
        int32_t sample_offset;
        int32_t duration_samples;
        int32_t symbol_type;      // 0=pulse-low, 1=pulse-high
        float amplitude;
    } DemodSymbol;
    // sizeof(DemodSymbol) = 16 bytes
    ```

    1. Create `src/lib/dsp/demod-processor.ts`:

    ```typescript
    import type { DemodSymbol } from '$lib/protocol/gen2-types';

    // WASM module type (Emscripten factory output)
    interface DemodModule {
      _demod_process(inputPtr: number, byteCount: number, sampleRate: number, outputPtr: number, globalOffset: number): number;
      _demod_reset(): void;
      _demod_get_noise_floor(): number;
      _demod_get_state(): number;
      _malloc(bytes: number): number;
      _free(ptr: number): void;
      HEAPU8: Uint8Array;
      HEAP32: Int32Array;
      HEAPF32: Float32Array;
    }

    const SYMBOL_STRUCT_SIZE = 16; // 4 int32 fields = 16 bytes per DemodSymbol

    export class DemodProcessor {
      private module: DemodModule | null = null;
      private inputPtr: number = 0;
      private outputPtr: number = 0;
      private maxSamples: number = 0;

      async init(maxSamples: number = 16384): Promise<void> {
        // Dynamic import of WASM factory -- works in both worker and test contexts
        const createModule = (await import('../wasm/demod.mjs')).default;
        this.module = await createModule() as DemodModule;
        this.maxSamples = maxSamples;
        // Allocate input buffer: maxSamples * 2 bytes (IQ pairs)
        this.inputPtr = this.module._malloc(maxSamples * 2);
        // Allocate output buffer: maxSamples * SYMBOL_STRUCT_SIZE (worst case: 1 symbol per sample)
        this.outputPtr = this.module._malloc(maxSamples * SYMBOL_STRUCT_SIZE);
      }

      process(iqData: Uint8Array, length: number, sampleRate: number, globalSampleOffset: number = 0): DemodSymbol[] {
        if (!this.module) throw new Error('DemodProcessor not initialized');
        const byteCount = Math.min(length, this.maxSamples * 2);

        // Copy IQ data into WASM heap
        this.module.HEAPU8.set(iqData.subarray(0, byteCount), this.inputPtr);

        // Call C function
        const symbolCount = this.module._demod_process(
          this.inputPtr, byteCount, sampleRate, this.outputPtr, globalSampleOffset
        );

        // Read results from WASM heap
        return this.readSymbols(symbolCount);
      }

      reset(): void {
        if (this.module) this.module._demod_reset();
      }

      getNoiseFloor(): number {
        return this.module?._demod_get_noise_floor() ?? 0;
      }

      dispose(): void {
        if (this.module) {
          this.module._free(this.inputPtr);
          this.module._free(this.outputPtr);
          this.module = null;
        }
      }

      private readSymbols(count: number): DemodSymbol[] {
        if (!this.module || count === 0) return [];
        const symbols: DemodSymbol[] = [];
        const baseOffset = this.outputPtr / 4; // int32 offset

        for (let i = 0; i < count; i++) {
          const idx = baseOffset + i * 4; // 4 int32s per symbol
          symbols.push({
            type: this.module.HEAP32[idx + 2] === 1 ? 'pulse-high' : 'pulse-low',
            sampleOffset: this.module.HEAP32[idx],
            durationSamples: this.module.HEAP32[idx + 1],
            amplitude: this.module.HEAPF32[idx + 3],
          });
        }
        return symbols;
      }
    }
    ```

      // silence: N samples of (128,128)
      // signal: N samples of (200,200) = strong carrier
      const totalSamples = pattern.reduce((sum, p) => sum + (p.silence + p.signal), 0);
      const data = new Uint8Array(totalSamples * 2);
      let offset = 0;
      for (const { silence, signal } of pattern) {
